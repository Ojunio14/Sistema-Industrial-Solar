reintegração de geologia/clima/biomas. `.gdignore` exclui o snapshot do registro
de classes e do runtime. Não carregar estes scripts na cena atual.

implementação executável junto do planeta novo. A migração futura deverá portar
as autoridades separadas para o contrato `PlanetShape.sample_base_height`.
